# Product Guidelines

## Brand Messaging

- **Tone:** Technical, precise, and educational.
- **Voice:** Authoritative yet approachable, focusing on clarity and utility.
- **Key Message:** GoNN is a foundational Go library for neural networks, offering basic components for diverse architectures.

- **Clarity:** All documentation should be clear, concise, and easy to understand for developers.
- **Examples:** Provide practical code examples for all functionalities.
- **Consistency:** Maintain consistent terminology and formatting throughout all project documentation.
